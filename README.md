## 1. Проблема и целевая аудитория

Глухой человек не может самостоятельно решить бытовое дело в аптеке, поликлинике,
банке или ЦОНе. Государство оплачивает **60 часов сурдоперевода в год** — это
около десяти минут в день, и записываться надо заранее. Всё остальное время
человек либо пишет в заметках телефона (а письменный русский для многих глухих —
второй язык, не родной), либо приводит с собой родственника — и тогда о диагнозе,
долге или конфликте узнаёт вся семья.

Вторая половина проблемы обычно остаётся незамеченной: **сотрудник по ту сторону
стойки тоже не может ответить**. У регистратора, кассира или врача нет способа
показать «подождите», «принесите паспорт», «это будет больно». Односторонние
субтитры эту половину не закрывают.

**Целевая аудитория:** глухие и слабослышащие; их слышащие родственники;
сотрудники организаций, обслуживающих людей.

## 2. Описание решения и ключевая AI/ML-логика

Qyran переводит **в обе стороны** и целиком работает на устройстве пользователя:
кадры с камеры не покидают браузер.

### Речь и текст → жест

1. Фраза перестраивается в жестовый порядок слов (`src/lib/glossing.ts`).
   Это не украшение: в июле 2026 на встрече с глухими нам сказали прямо, что
   пословный перевод они не понимают — у жестового языка своя грамматика.
   `Я вчера ходил в магазин с мамой` → `ВЧЕРА Я ХОДИЛ МАГАЗИН МАМОЙ`.
2. Для каждого слова берётся анимация: сначала из библиотеки **966 готовых
   жестов**, ретаргетированных из датасета SLOVO на скелет аватара; если слова
   там нет — процедурный словарь (`src/lib/signWords.ts`), где знак описан
   тройкой «форма кисти + позиция + движение», как в фонологии жестовых языков;
   если и там нет — дактиль по буквам (`src/lib/dactyl.ts`).
3. 3D-аватар на three.js проигрывает последовательность.

### Жест → речь

1. **MediaPipe Holistic** снимает 543 точки тела, рук и лица, 30 кадров в секунду.
2. Кадр канонизируется в 319-мерный вектор: координаты переводятся в систему
   координат тела, кисть нормируется на длину ладони отдельно от позы, считаются
   относительные расстояния и скорости (`ml/features.py`, побитовое зеркало на
   TypeScript — `src/lib/features.ts`).
3. Окно из 60 кадров классифицируется моделью **Conv1D + BiLSTM**, 4.08 млн
   параметров, 1001 класс. Модель весит **7.8 МБ** (fp16) и работает в браузере
   через **TensorFlow.js** — сервера в контуре разговора нет.
4. Распознанные знаки складываются в предложение и озвучиваются.

### Что здесь собственно ML, и какие цифры честные

| | значение |
|---|---|
| top-1 на **невиданных жестикулянтах** | **60.2%** |
| top-5 там же | 87.2% |
| top-1 при ограничении словарём площадки (208 знаков) | **80.6%** |
| вес модели в браузере | 7.8 МБ |

Оценка честная: официальный сплит SLOVO **не signer-disjoint** — 92 из 194
человек присутствуют и в обучении, и в тесте. Поэтому главная метрика считается
на 1652 клипах от 82 человек, которых модель не видела. Для сравнения, лучшая
опубликованная авторами SLOVO модель даёт 64.09% на **их** протоколе (с утечкой),
а Qyran на том же протоколе — 60.86%, при весе в 17 раз меньше и работе на
устройстве, а не на сервере.

Два приёма, давшие прирост, измерены и воспроизводимы:

* **Самообучение на позах.** Модель предобучена восстанавливать замаскированные
  кадры без единой метки (`ml/pretrain_masked.py`), затем дообучена на разметке.
  Прирост: 58.5% → 60.2% top-1 и 57.2% → 59.2% в потоковом режиме, при этом
  выигрыш сохраняется при любом бюджете ложных срабатываний.
* **Ограничение словарём сценария.** У конкретной стойки показывают не тысячу
  знаков, а две сотни. Зануление недопустимых классов перед argmax поднимает
  точность до 80.6% без переобучения (`ml/vocab_experiment.py`).

## 4. Локальный запуск

Нужен Node.js 20+.

```bash
git clone <этот-репозиторий>
cd qyran-web
npm install --legacy-peer-deps
npm run dev
```

Откроется на <http://localhost:5174>.

Экраны в режиме разработки выбираются параметром:

```bash
http://localhost:5174/?view=translator    # речь → жест
http://localhost:5174/?view=recognizer    # жест → речь
http://localhost:5174/?view=studio        # запись новых жестов
```

Ограничение словарём площадки включается так:

```bash
http://localhost:5174/?view=recognizer&vocab=counter_lean
```

Сборка в продакшен:

```bash
npm run build
```

### Обучение и проверки (необязательно)

Конвейер обучения лежит в `ml/` и в развёрнутое приложение не входит.
Датасет SLOVO надо скачать отдельно (см. `NOTICE`).

```bash
ml/venv/bin/python ml/train_rsl.py          # обучение распознавателя
ml/venv/bin/python ml/evaluate.py           # честная оценка
ml/venv/bin/python ml/vocab_experiment.py   # эффект сужения словаря
```

Offline-проверки решателя и отрисовки — без камеры, на настоящем скелете и
настоящих кадрах:

```bash
node scripts/check-hand-orientation.mjs   # не вывернута ли ладонь
node scripts/check-arm-placement.mjs      # куда попадают запястья
node scripts/check-stance.mjs             # поза покоя аватара
node scripts/check-glossing.mjs           # фраза → жестовый порядок
```

## 5. Демонстрация

**Живая ссылка: <https://qyran-web.vercel.app>**

Развёрнутое приложение, доступное жюри для самостоятельной проверки без
установки, регистрации и без собственных ключей к платным API (их в проекте нет
вовсе — все модели работают на устройстве пользователя). Это соответствует
варианту Б пункта 5.4 Положения.

Сценарий для проверки:

1. Открыть ссылку → «Речь → жест» → написать `привет мама` → аватар покажет
   жестами.
2. «Жест → речь» → разрешить камеру → показать знак → появится слово и озвучка.
3. Переключатель языка интерфейса: казахский, русский, английский.

## 7. Дальнейшее развитие

Подробная дорожная карта с этапами, метриками и критериями остановки —
[ROADMAP.md](ROADMAP.md). Коротко, по приоритету:

1. **Top-5 с подтверждением тапом.** top-5 внутри словаря площадки — 95.6%.
   Один тап превращает «угадывает два знака из трёх» в «верное слово почти
   всегда». Самый крупный продуктовый рычаг.
2. **Мимика.** В риге аватара уже есть 14 морф-таргетов (брови, рот, моргание),
   но они не подключены. В жестовом языке лицом показывают вопрос, отрицание и
   условие — без него половина грамматики не передаётся.
3. **Непрерывное распознавание.** Сейчас модель различает изолированные знаки;
   связная речь — другая задача (CTC / сегментация потока).
4. **Свой корпус.** Измерено на собственных данных: при одинаковом числе клипов
   знаки, показанные ≥14 разными людьми, распознаются на **83.8%**, а показанные
   ≤7 людьми — на **59.0%**. Значит собирать надо разных людей, а не больше
   дублей от одного.

## Честные ограничения

Проект сознательно не обещает того, чего не умеет:

* это **не замена сурдопереводчику**, а инструмент для быстрых типовых дел;
* высокая точность достигается **внутри словаря конкретной площадки**, а не «в
  любых сферах»: шире словарь — ниже точность, и это измерено;
* распознаются **отдельные знаки**, а не связная речь;
* аватар пока показывает жесты руками без мимики;
* глубина с одной камеры принципиально приблизительна.
